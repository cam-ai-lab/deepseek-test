# Part 2 — Testing inside the box

In this part we work from the inside out, through every tier of the lab's existing suite. We start
with the smallest, fastest tests — pure unit tests of arithmetic — and widen the scope one step at a
time: frozen regression anchors, architecture rules, Spring slices, a real PostgreSQL in a
container, and an HTTP adapter tested against a stub server.

Each chapter adds one new *kind of realism* and asks the same question: **what can this test see
that the previous one couldn't, and what did that realism cost?** The part ends with chapter 11,
which looks at the build machinery — Gradle test suites, classpath guards, a context budget and
coverage — that keeps a growing suite fast and honest.
